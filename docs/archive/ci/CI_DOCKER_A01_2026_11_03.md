## Risques, performances et validations restantes

Le passage au contexte local inclut les fichiers du checkout selon `.dockerignore`.
La CI utilise un checkout neuf ; localement les sources doivent être inspectées
avant construction. Aucun checkout de branche mutable n'est substitué au SHA.
Les paquets de métadonnées générés restent adressés par leurs overlays `cwd://`.

Il n'y a pas de comparaison de performance avant/après comparable pour ce lot.
L'échec PR initial survenait avant compilation ; comparer ce délai à un build
réussi ne mesurerait pas une accélération. Le premier build local peut compiler
des dépendances froides. Ce build a duré environ **13 min 26 s** selon BuildKit,
dont 240,4 s pour le stage de dépendances et 539,5 s pour la compilation finale.
Ces durées sont celles d’un seul run local, sans comparaison avant/après.
Aucun gain CPU/RSS/latence du lecteur n'est revendiqué.
Le risque principal est une différence de résolution locale des fichiers Bake ;
le plan et les overlays sont contrôlés, les événements distants restent à rejouer.

A01 reste **partiel** jusqu'à validation GitHub push/PR/dispatch et parcours tag
prévu par le workflow Release. Pas de publication, push, déploiement NAS ou test
sur deux machines physiques effectué par ce lot. La CI complète reste rouge
sur la base courante indépendamment de ce correctif.
